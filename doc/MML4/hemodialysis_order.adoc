==== エレメント解説
==== M28. mmlHdo:HemodialysysOrderModule
【内容】透析指示情報モジュール． +
本モジュールには患者情報を記載する要素名がないので，患者情報モジュール（mmlPi）
を使用すること．

【属性】
[options="header"]
|===
|属性名|データ型|省略|説明
|mmlHdo:version|string|#REQUIRED|バージョン
|mmlHdo:createDate|dateTime|#REQUIRED|作成日
|===

==== M28.1. mmlHdo:HemoDialysisHistory
【内容】透析に関する履歴 +
【省略】省略不可

==== M28.1.1 mmlFc:Facility
【内容】施設情報、構造はMML共通形式を参照．施設情報は本モジュールを作成した施設．+
【省略】可．ただし，本モジュールに記載しない場合は「透析履歴情報モジュール」または「透析記録情報モジュール」のどちらかに記載すること．
