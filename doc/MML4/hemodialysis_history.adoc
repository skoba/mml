==== エレメント解説
==== M27. mmlHdh:HemoDialysysHistoryModule
【内容】透析履歴情報モジュール．+
//本モジュールには患者情報を記載する要素名がないので，患者情報モジュール（mmlPi）を使用すること．
【属性】
[options="header"]
|===
|属性名|データ型|省略|説明
|mmlHdh:version|string|#REQUIRED|バージョン
|mmlHdh:createDate|string|#REQUIRED|作成日
|===

==== M27.1. mmlHdh:HemoDialysisHistory
【内容】透析に関する履歴 +
【省略】省略不可

==== M27.1.1 mmlFc:Facility
【内容】施設情報、構造はMML共通形式を参照．施設情報は本モジュールを作成した施
設．+
【省略】可．ただし，本モジュールに記載しない場合は「透析指示情報モジュール」または「透析記録情報モジュール」のどちらかに記載すること．+

==== M27.1.2　mmlHdh:note
【内容】メモ +
【省略】省略可

==== M27.1.3　mmlHdh:hdIntroduction
【内容】透析導入情報 +
【省略】省略不可 +
【繰り返し設定】繰り返しあり．表記法が複数あれば繰り返す．

==== M27.1.3.1　mmlHdh:hdDiagnosis
【内容】原疾患 +
【省略】省略可 +
【属性】
[options="header"]
|===
|属性名|データ型|省略|説明
|mmlHdh:code|string|#IMPLIED|疾患コード
|mmlHdh:system|string|#IMPLIED|疾患コード体系
|===

==== M27.1.3.2 mmlHdh:hdIntroDate
【内容】透析導入日 +
【データ型】date +
【省略】省略可

==== M27.1.3.3 mmlFc:Facility
【内容】導入施設。構造はMML共通形式(mmlFc:Facility)を参照． +
【省略】省略可

==== M27.1.3.4 mmlHdh:vascularAccess
【内容】バスキュラーアクセス +
【省略】省略不可 +
【繰り返し設定】繰り返しあり．表記法が複数あれば繰り返す． +
【属性】
[options="header"]
|===
|属性名|データ型|省略|説明
|mmlHdh:vaStatus|string|#IMPLIED|バスキュラーアクセス状態、良：active，不良： inactive 
|===

==== M27.1.4.1 mmlHdh:dateMade
【内容】バスキュラーアクセス作成日 +
【データ型】date +
【省略】省略可

==== M27.1.4.2 mmlHdh:dateFirstUse
【内容】バスキュラーアクセス使用開始日 +
【データ型】date +
【省略】省略可

==== M27.1.4.3 mmlHdh:dateEnd
【内容】バスキュラーアクセス使用終了日 +
【データ型】date +
【省略】省略可

==== M27.1.4.4 mmlHdh:location
【内容】バスキュラーアクセス部位名、漢字を推奨。MMLテーブル『hdVaCodeTable01 HDバスキュラーアクセスコード』を使用．
【データ型】string
【属性】
[options="header"]
|===
|属性名|データ型|省略|説明
|mmlHdh:code|string|#IMPLIED|
|mmlHdh:tableId|string|#IMPLIED|hdVaCodeTable01
|===

【例】
[source, xml]
<mmlHdh:location mmlHdh:code=“0102” mmlHdh:tableId=hdVaCodeTable01>左前腕</mmlHdh:location>

==== M27.1.4.5mmlHdh:note
【内容】メモ +
【データ型】string +
【省略】省略可
