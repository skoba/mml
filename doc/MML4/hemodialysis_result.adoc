==== エレメント解説
===== M29. mmlHdr:HemodialysysResultModule
【内容】透析記録情報モジュール． +
本モジュールには患者情報を記載する要素名がないので，患者情報モジュール（mmlPi）
を使用すること． +
【属性】
[options="header"]
|===
|属性名|データ型|省略|説明
|mmlHdr:version|string|#REQUIRED|バージョン
|mmlHdr:createDate|dateTime|#REQUIRED|作成日
|===

==== M29.1. mmlHdr:HemoDialysisResult
【内容】透析に関する記録 +
【省略】省略不可


==== M29.1.1. mmlFc:Facility
【内容】施設情報、構造はMML共通形式を参照。施設情報は本モジュールを作成した施設。
【省略】可．ただし，本モジュールに記載しない場合は「透析履歴情報モジュール」また
は「透析指示情報モジュール」のどちらかに記載すること．

==== M29.1.2. mmlHdr:note
【内容】備考 +
【省略】可
